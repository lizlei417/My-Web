# My-Web v8.0 流光账本

这是 My-Web v8.0 的完整记账页面，由门户 iframe 路由载入。页面复用门户侧栏、全局主题、音乐播放器和账号状态；游客数据仅保存在当前浏览器，登录用户数据通过 `PortalAccountData` 映射到 Supabase。

## 已实现

- 收入 / 支出账目新增、编辑、删除
- 时间自定义，新增时默认当前本地日期与时间
- 事件、备注、事件分类、金额、货币
- 支出与收入分类的新增、编辑、删除及自动归入“其他”；内置 Emoji 图标选择器
- CNY、HKD、USD、EUR、JPY、GBP 六种货币；以 HKD 为内部换算基准，并可全局切换显示货币
- 本月、上月、近 30 天、今年、自定义日期范围
- 总支出、总收入和周期比较
- 收入 / 支出分类占比圆环图；日、周、月收支趋势切换与滚轮缩放
- 明细搜索、收支与分类联动筛选
- 明细按年份、月份和日期分组；账目行不重复显示时间，空备注不显示占位文字
- 明细金额统一外显为 HKD；非港币账目可悬停金额查看实际收付的原币金额
- 全部下拉框、日期与时间选择器均使用项目自定义面板，不调用浏览器默认选择界面
- 以 `user:{id}:bookkeepingLedger:v1` 为键进行账号隔离，并通过 `bookkeeping.state` 云端键同步
- 桌面端和移动端响应式布局、减少动态效果偏好支持

## 运行

从 `v8.0` 的上一级目录启动静态文件服务器，例如：

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/v8.0/index.html?page=bookkeeping/index.html`。

## 门户接入点

- `../index.html`：路由白名单、主导航、激活态和组件恢复顺序
- `../shared-nav.js`：直接打开重定向、子页导航排序
- `../account-data.js`：`bookkeeping.state` 的账号数据映射
- 本页不创建第二个音乐播放器；播放器由门户外壳持续持有，切换页面不会中断
